# nitseyj.github.io

Personal portfolio of Justin Phoo Hoe Yin. A single static page: all markup, styles and script are in `index.html`.

## Preview locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Deploy
Push to the `main` branch of a public repo named `nitseyj.github.io`. GitHub Pages serves it at https://nitseyj.github.io
